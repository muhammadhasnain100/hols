# Brand fonts (required for exact brand match)

Place licensed `.woff2` files in this folder, then import `brand-fonts.css` from `src/app/globals.css`.

Until then, the site uses free stand-ins with the same weights:
- **DM Sans** → Google Sans (400 / 500 / 600 / 700)
- **Outfit** → Gilroy (300 / 800)

## Google Sans (primary)

| File | Weight |
|------|--------|
| `GoogleSans-Regular.woff2` | 400 |
| `GoogleSans-Medium.woff2` | 500 |
| `GoogleSans-SemiBold.woff2` | 600 |
| `GoogleSans-Bold.woff2` | 700 |

## Gilroy (secondary)

| File | Weight |
|------|--------|
| `Gilroy-Light.woff2` | 300 |
| `Gilroy-ExtraBold.woff2` | 800 |

## Type scale (live)

| Role | Font | Size | Weight |
|------|------|------|--------|
| Heading | Google Sans | 60px | Bold |
| Sub-heading | Google Sans | 34px | Regular |
| Body | Gilroy | 18px | Light |
| Caption | Google Sans | 14px | Regular |
